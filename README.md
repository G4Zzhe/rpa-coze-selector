## 技术栈

影刀 RPA / 飞书多维表格 API / Coze 扣子 / AI 工作流

## 项目概述

搭建“抖音电商罗盘榜单抓取 → 飞书存储 → AI 选品分析”全链路自动化系统，实现每日自动产出选品决策报告。

## 整体业务链路
[影刀 RPA] → [飞书多维表格] → [Coze 扣子智能体] → [选品报告]
↓ ↓ ↓
榜单抓取 数据持久化 AI 自动分析

## 各层详解

### RPA 抓取层（影刀）
- **登录双路径容错**：Cookie 缓存持久化复用 + 手动扫码兜底【详见考核文档】
- **双榜单分页抓取**：近 7 天 + 近 1 天，各 20 页 TOP200 商品
- **采集字段**：标题、价格、销量、成交结构、商品链接等 10+ 字段
- **模拟真人操作**：随机 2-5 秒等待，降低风控
- **分页重试**：失败自动重试 2 次

### 数据存储层（飞书多维表格）
- 调用飞书多维表格开放 API 自动写入
- **自动去重**：根据商品链接判断，已存在则覆盖更新【详见考核文档】
- Token 权限管理（最小化原则：仅开放表格读写权限）

### AI 分析层（Coze 扣子）
- 安装官方「飞书多维表格」插件，授权飞书账号[reference:19]
- 工作流通过飞书 API 实时拉取全量数据[reference:20]
- **自动数据清洗**：过滤空值、缺失链接、无主图商品
- **自动分类**：短视频潜力品 vs 短期飙升品
- **输出模块**：
  - ① 优质潜力商品清单（含投放建议）
  - ② 高风险避雷清单（标注风险原因）
  - ③ 类目机会分析（增速最高 3 个类目）
  - ④ 运营方案（自播/达人/自然流）

### 自动化触发
- 配置工作流**自动触发**：飞书表格新增数据后自动执行分析
- 输出标准化选品报告（可推送至企业微信/钉钉）

## 容错与安全

| 场景 | 处理方式 |
|------|----------|
| 页面加载超时/元素找不到 | 自动重试 2 次，超时告警 |
| 飞书 API 请求超限/Token 失效 | 输出文字告警，终止写入 |
| 登录会话过期/人脸验证 | 人工干预提示，不卡死脚本 |
| 大批量抓取限流 | 增加间隔休眠，规避风控 |
| **安全规范** | 无明文账号/Token 硬编码，Cookie 仅本地存储【详见考核文档】 |
